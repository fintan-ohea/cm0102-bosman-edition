## MUST-FIX

### 1. Cup group stages are freed and redrawn when anything reads the cup's round table (verified)

- Where: `src/recomp_rt/win/season_cup_groups.c:257-288`. The guard `inner` (line 254) is never set, so only `stage != 0xff` filters.
- Cause: Comp::build_match_date_list 0x48d500 calls vtable +0x3c with stage -1 (`or ebx,-1` at 0x48d5a1, `call [edx+0x3c]` at 0x48d5c4) for each comp with +0x2c >= 0. That call reaches the wraps `groups_sco_lge_cup` (0x7efcb0) and `groups_eng_auto_cup` (0x56ade0), and `cups_eng_cc_cup`, `cups_tur_cup` and `cups_rus_cup` in `season_kind_cups.c`. Line 278 then runs `free_stages`, which deletes the live League_Stage and Cup_Stage objects and sets +0x30 to -1. For EngAutoCup, `merge_auto_halves` (line 274) runs again and reads 2n entries from a half that holds n.
- Callers of 0x48d500: comp_screens_draw_schedule_tab (0x4947a0), PLAYER_SEARCH::start_scout_assignment (0x7ae9c0) and SCOUT_MANAGER::collect_current_duty_comps (0x7f7010). So it can run with no screen open.
- Scenario: start 2016/17 or later, Scotland, England, Turkey or Russia loaded, rules on or off, after the groups are drawn.
- Fix: act only for the set-up callers, with a return-address test as `season_uefa_cup.c:347-366` and `season_uefa.c:589-597` do (set_up_rounds calls at 0x4c160a, return 0x4c160d, plus the constructor sites). Or set `inner` round the real caller. Remove the dead guard.
- Sent to the lead at 2026-10-20 night.

### 2. Base saves dated 2007, 2011, 2015 and later load with a different heap (probable, Q152)

- Where: `tools/recomp/seasons.py:435`, the patch at 0x57D021: `|| R16(esi + 0x40u) != 0x7d2u`, with no season gate.
- Cause: the EuroChampQual constructor 0x57ce10 is called at 0x830d6c with the game year from [0xae2c92] (0x830d3f). It rounds year-1 up to the campaign year (+0x40). At 0x57d01a and 0x57d021, when the year is past the campaign, the original calls load_2002_campaign 0x580bd0, which allocates. The patch skips that call for each campaign other than 2002, in the base game too. Its comment checks only the new game (year 2001).
- Scenario: rules off, 2001/02 start, 3.9.68. Play to 2007, save, load. 0.5.1 runs load_2002_campaign in the constructor and 0.6.0 does not.
- Not confirmed: that the save load has set [0xae2c92] to the save's date before the comp table is built. `season.c:360` says the load builds the table from the game year. A same-save check on a base save dated 2007 settles it.
- Fix: gate the extra test, for example a helper that returns 0 when `!season_intl_on()` or the start year is 2001.
- Sent to the lead at 2026-10-20 night.

## SHOULD-FIX

3. **International finals stop after their last table row** (E, partly verified). `season_intl_rules.c:80-105`, table `season_intl_table.c`. `rt_intl_first_year` returns `IDLE_YEAR` when no edition is found from the start season. The last Copa América (`goldcup`), Olympic and OFC rows are 2023/24 (lines 48, 54, 60), and `tools/seasons/make_intl.py:52-54` skips the 2028 rows. So a 2025/26 start never has a Copa América, Olympic football or OFC Nations Cup, with rules on or off. With rules on, each class waits at 2200 after its last row: no Euro after 2028 and no World Cup after 2030. The Gold Cup and the Nations League repeat their last edition (`season_gold_cup.c:203-222`, `season_nl.c:275-294`), so the slices disagree. Spec line 87 (Q248) says "the rules then stay". Fix: after the last edition, repeat it with the original step, as `gold_edition` does. Keep `IDLE_YEAR` for the Confederations Cup only. The code comment says this is intended, so Max decides.

4. **Domestic cup groups: base rounds cut on a failed draw** (D, agent). `season_cup_groups.c:370-375` with `:283`. Line 283 cuts the round count to `base_rounds`, then the failure path sets +0x2c to 0 and the class's rounds play from a table that holds only the base rounds. Turkish Cup group seasons with a club count that does not fit the groups. Fix: keep the full round count until the draw succeeds.

5. **League cups that wait for a later edition make fixtures at the new game** (D, agent). `season_kind_cup_breaks.c:129-149`. Only `next == SEASON_CUPS_NEVER` blocks create_fixtures. Rules on, start 2003 to 2011 with Korea, 2004 to 2019 with Ireland, 2020 with Italy, Northern Ireland or Wales. Fixtures dated years ahead go into the clubs' lists. Fix: use the never path at the new game and let the season change bring the cup back.

6. **Euro qualifying stage count stays at 9** (E, agent). `season_intl_euroq.c:220-221`. `euroq_advance` writes +0x2c = 9 and 0x57eb20 never resets it. The next ten-group campaign loses its play-off. After a load, `euroq_group_stage` (line 183) writes 4 bytes past a 9-entry stage array (heap corruption) when a path build failed earlier (`season_nl_euro.c:340`). Fix: restore 10 in `rt_euroq_rules` and size the array again.

7. **Greek second group one season ahead when made mid-game** (C, agent). `season_divisions.c:1144` with `:1169` and `season_comps.c:435`. Greece, rules on, start 2016 to 2020 and play to July 2021 (or a start before 2013, to July 2013). `comps_entry` makes the group with year S, then `gre_swap` starts it again (S+1). Its clubs play no league in season S. Fix: in `gre_swap`, start the group only when its year is below `next`. Check against the slice 20b round.

8. **Inter-confederation ties lost after a save** (B, agent). `season_intl_qual.c:259-265`, used at `season_intl.c:487-507`. `built[]` and `n_built` are not saved. A save and load between mid-November and the World Cup draw gives the tie's slot to the strongest free nation, and the tie winner stays out. Fix: rebuild the list at the draw from the qualifying stages, or save it in the season part.
